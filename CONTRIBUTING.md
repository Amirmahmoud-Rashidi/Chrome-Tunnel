# Contributing to Chrome Tunnel

Thank you for your interest in improving this project! Please read the following guidelines before reporting a bug or submitting changes.

## Bug Reports

1. **Supported Protocols:** Before submitting a report, please note that this tool only supports **HTTP, HTTPS, and WebSocket** connections. If your issue is outside of these protocols, do not report it.
2. **Steps to Reproduce:** When you encounter an issue—such as a fetch error (which is the most common issue)—please write a step-by-step description of everything you did before the error occurred. If the problem happened after a long session, you can just mention your last 10 actions.
3. **Log Files:** Please include the log file generated in the `native-host` folder. Before sending the file, **make sure to delete any sensitive information** and only include the last 50 error logs.

## Improving the Repo

1. **Contribution Policy:** Please note that this is a sensitive tool, so I cannot add direct contributors to the main repository. To improve this repo, please **fork the project, apply your changes, and submit a pull request**.
2. **Privacy and Security:** Do not include any code that sends data to any server other than the request destination. If any malicious or unauthorized data-sharing code is found, **it will be reported to GitHub Support immediately**.
